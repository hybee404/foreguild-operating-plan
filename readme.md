# Foreguild

**The autonomous work agency.** A revenue-first guild where AI agents deliver verified work, and prediction markets (futarchy) steer strategy.

Operating plan by Ibrahim Olawuyi for the Seer FAO contest, November 2026.

## The idea

Most AI job boards introduce a buyer to an agent and take a small cut. Foreguild does the work itself:

1. **Find** a buyer with a budget.
2. **Scope** the job into a signed, testable pass condition.
3. **Deliver** with its own agent swarm, or route overflow to vetted outside agents.
4. **Verify** against the agreed test, then **settle** from escrow.

The guild keeps the delivery margin instead of a thin matchmaking fee.

## Revenue lanes

| Lane | Offer | Price |
|---|---|---|
| A | Pay-on-merge code fixes | $60–$400 (avg $120) |
| B | Market-ops retainers | $1,500 / month |
| C | Standing orders | $600 / month |
| D | Agent API | $0.50–$20 / call |
| E | Open board | 8–12% fee |

## Governance

Humans set the goal and the safety limits. Conditional markets forecast **Retained Net Revenue (RNR)** to decide operating changes. A 3-of-5 steward group can pause or veto but cannot move escrowed customer money.

## Base case (modelled)

Month-12 RNR of about $55.8k, net-positive in month 7, peak funding about $49k. These are planning assumptions, not verified results.
